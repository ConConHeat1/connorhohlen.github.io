How it started

I started this site the summer after sophomore year to show my projects and learn how to put a website online with its own domain name. Over time, it became a portfolio where employers and other students can get to know me through the things I build.

The current version has a scroll-driven project carousel, individual project pages, and a circuit-inspired homepage. I use HTML, CSS, and JavaScript directly, publish through GitHub Pages, and test navigation and layouts as the site grows.
